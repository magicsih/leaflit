## 범위와 남은 확인

이번 회차는 Debug 앱의 위 기능을 확인했다. Release 앱, 실제 네트워크 차단 상태의 오프라인 실행, 밝은 모드, 작은 창과 200% 확대, VoiceOver 음성, 갱신과 오류 복구, Finder 드롭, 성능 측정은 이 회차에서 실행하지 않았다. 수식이 보였다는 사실을 네트워크 차단 검증 통과로 바꾸지 않는다.

Fixtures는 읽기만 했고 종료 시 `git diff -- Fixtures`가 비어 있었다. 열람 전 해시를 이번 회차에서 채취하지 않았으므로 해시 비교 통과로 기록하지 않는다.

Mermaid 글자 누락과 View > Back 메뉴를 구현자에게 전달했다. 검색 필드 붙여넣기 실패도 전달했으며, 복사 결과는 추가 검증이 필요하다. 코드는 수정하지 않았다.

종료 전 도구 막대 Back으로 Welcome.md에 복귀한 뒤 ⌘Q로 앱을 종료했다. 이후 앱 프로세스 조회 결과가 비어 있었으며 검수자가 시작한 다른 테스트 프로세스는 없다. UI 제어를 구현자에게 반환한다.
