Leaflit 0.3.1 fixes oversized titles when opening Markdown files with YAML front matter.

- Read starts with the document body instead of combining metadata into a large heading. Outline lists only the body's headings.
- Metadata remains available in Source. Original line positions are preserved when jumping from a formula or diagram error to its source. Incomplete metadata blocks remain visible.

Apple Silicon, macOS 14 or later. This remains a preview distributed through GitHub Releases and the personal Homebrew tap.

### Install or upgrade

```sh
brew install --cask magicsih/tap/leaflit
# Existing Homebrew installation:
brew update
brew upgrade --cask magicsih/tap/leaflit
leaflit ./plan.md
```

Or extract `Leaflit-0.3.1-macos-arm64.zip` and move Leaflit.app to Applications. The ZIP includes a launcher. Verify the archive with the attached `SHA256SUMS`; `release-manifest.json` records its exact source and signed identity.

Known limitations from [0.3.0](https://github.com/magicsih/leaflit/releases/tag/v0.3.0), including earlier-macOS coverage, formula copying and the initial inactive Read observation, remain separate open follow-ups. This patch does not add Intel support or automatic updates.
