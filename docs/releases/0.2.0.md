# Leaflit 0.2.0 preview

Read Markdown from your terminal with a new Files and Outline sidebar and a dedicated Leaf Page app icon.

- Browse an explicitly chosen folder in **Files** and open Markdown in the current reading window, with Back for document navigation.
- Switch to **Outline** to jump to document headings and follow the current section while reading. Switch modes without losing the document, search or reading position.
- Collapse the sidebar when you want more reading space. Use **Open Folder…** (Shift-Command-O) and **Toggle Sidebar** (Control-Command-S) from the keyboard.
- Keep reading in small windows and at large text sizes, with corrections for narrow navigation controls and rendering progress after appearance changes.
- Recognize Leaflit by its centered page-and-leaf icon. The [website](https://magicsih.github.io/leaflit/) explains the terminal reading workflow and shows actual app screens.

## Install or upgrade

Download `Leaflit-0.2.0-macos-arm64.zip` from this release, extract it and move Leaflit.app to Applications. The personal Homebrew tap installs the app and launcher together:

```sh
brew install --cask magicsih/tap/leaflit
# If already installed:
brew update
brew upgrade --cask magicsih/tap/leaflit
leaflit ./plan.md
```

Apple Silicon only, macOS 14 or later. Runtime verification covers Apple M3 on macOS 26.6.2; earlier supported macOS versions remain unverified. The release provides a SHA-256 checksum and source/signing/notarization manifest. This is a preview distributed through the personal tap, separate from official `homebrew/cask` acceptance.

## Known limitations

The app remains read-only. Printing, PDF export, syntax highlighting, Obsidian-specific syntax and automatic updates are not included.

Memory remains above the original 60MiB comparison target. [Resource measurements](https://github.com/magicsih/leaflit/blob/main/docs/qa/sidebar-resources.md) identify their measured candidate, inputs and ranges; this icon/distribution update does not establish a new performance result. Follow-ups cover [ordinary memory](https://github.com/magicsih/leaflit/issues/1), [post-close memory](https://github.com/magicsih/leaflit/issues/2) and [startup latency](https://github.com/magicsih/leaflit/issues/3).

Remaining verification includes [spoken VoiceOver](https://github.com/magicsih/leaflit/issues/4), [earlier macOS](https://github.com/magicsih/leaflit/issues/5), [actual Finder-to-window drops](https://github.com/magicsih/leaflit/issues/8), [network-isolated execution](https://github.com/magicsih/leaflit/issues/12), [sidebar width persistence](https://github.com/magicsih/leaflit/issues/13) and [additional icon surfaces](https://github.com/magicsih/leaflit/issues/9). These are not recorded as passed. The [sidebar QA history](https://github.com/magicsih/leaflit/blob/main/docs/qa/sidebar-report.md) preserves the three review rounds, corrections and coverage limits.

## Distribution verification

The exact archive is Developer ID signed, accepted by Apple notarization, stapled and accepted by Gatekeeper. Its signed artifact and unauthenticated public download were each launched independently. Files, Outline, rendered Mermaid/math, relative navigation, Back and the bundled launcher have separately recorded execution evidence.

The personal Homebrew cask points to the immutable version/checksum. An isolated installation retained quarantine, passed signature/ticket/Gatekeeper checks and launched after the normal macOS first-open confirmation; its own bundled command opened a space-containing file. The existing global 0.1.0 installation was preserved, so a global CLI upgrade was not executed. Homebrew syntax/style passed; the full online audit remains failed on the preview-policy check. See the [distribution verification report](https://github.com/magicsih/leaflit/blob/main/docs/releases/0.2.0-verification.md) for exact identities, initial attempts and limits.
