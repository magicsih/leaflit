# Leaflit 0.1.0 preview

Leaflit opens Markdown files in a focused macOS reading window, with Mermaid diagrams and LaTeX math available offline.

- Open files from Finder, the Open menu or the `leaflit` command, with separate windows for separate documents.
- Read tables, task lists, code blocks and local images; search, copy, zoom and follow relative document links with Back.
- See saved changes automatically, including files replaced during saving, while keeping your reading position.
- Read in system light or dark appearance. Raw HTML is shown as text and remote document resources are blocked.

## Install

Download `Leaflit-0.1.0-macos-arm64.zip` from this release, extract it and move Leaflit.app to Applications. The archive also includes a standalone launcher; Homebrew installs the app and command together:

```sh
brew install --cask magicsih/tap/leaflit
```

Apple Silicon only. The build targets macOS 14 or later; actual runtime verification currently covers Apple M3 on macOS 26.6.2. The public archive includes a release manifest and SHA-256 checksum.

## Known limitations

Memory use exceeds the initial comparison target, and some runs retain WebKit memory after the last window closes. [Memory profiling](https://github.com/magicsih/leaflit/issues/1), [window teardown](https://github.com/magicsih/leaflit/issues/2) and [startup performance](https://github.com/magicsih/leaflit/issues/3) are follow-up work.

Spoken VoiceOver navigation and earlier macOS runtime verification remain incomplete: [accessibility](https://github.com/magicsih/leaflit/issues/4), [compatibility](https://github.com/magicsih/leaflit/issues/5). Editing, printing, PDF export, syntax highlighting and automatic updates are outside this preview. See the [QA report](https://github.com/magicsih/leaflit/blob/main/docs/qa/report.md) and [memory measurements](https://github.com/magicsih/leaflit/blob/main/docs/qa/memory-analysis.md) for measured results and verification limits.

## Distribution verification

The release archive is Developer ID signed, accepted by Apple notarization, stapled and accepted by Gatekeeper. The extracted signed app displayed the preview document with Mermaid and math; its bundled command, relative navigation, Back and a user-clicked link to the default browser passed on Apple M3 with macOS 26.6.2. The source document hash remained unchanged. Actual Finder-to-window drag and drop remains [unverified](https://github.com/magicsih/leaflit/issues/8).

Homebrew installation and the installed `leaflit` command were verified with quarantine retained. The personal tap is available; the online cask audit reports the prerelease-policy failure described in [official cask readiness](https://github.com/magicsih/leaflit/issues/6). See the [distribution verification report](https://github.com/magicsih/leaflit/blob/main/docs/releases/0.1.0-verification.md).
