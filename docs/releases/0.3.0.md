Leaflit 0.3.0 adds explicit Source editing to the read-first macOS viewer. Open Markdown from your terminal, read it, and make a small correction when you need one.

- Switch between **Read** and **Source** with Option-Command-1 and Option-Command-2. Preview unsaved edits in Read, then save explicitly with Command-S. There is no autosave or automatic formatting.
- Jump from a broken Mermaid diagram or formula to its original source. Source includes native Find, Undo/Redo and a separate Save a Copy action.
- Keep drafts through external saves, replacements and read failures. Navigation, window closing and quitting offer Save, Cancel and Discard when changes remain.
- Restore sidebar width after small windows and Find, and keep Outline expansion and selection while the body refreshes.
- Improve repeated-heading parsing, math stylesheet readiness and document transitions. Startup and memory remain active performance work; measured results are linked below.

Apple Silicon only, macOS 14 or later. Runtime verification covers Apple M3 on macOS 26.6.2; older macOS versions have not been executed. The app is signed with Developer ID, notarized and stapled. This remains a preview in the personal tap, separate from official Homebrew cask acceptance.

### Install or upgrade

```sh
brew install --cask magicsih/tap/leaflit
# Existing Homebrew installation:
brew update
brew upgrade --cask magicsih/tap/leaflit
leaflit ./plan.md
```

Or extract `Leaflit-0.3.0-macos-arm64.zip` and move Leaflit.app to Applications. The ZIP includes a launcher; Homebrew installs the command for you. Verify the ZIP with the attached `SHA256SUMS` and inspect `release-manifest.json` for its exact source and signed identity.

### Known limits

An inactive public-download capture initially showed a blank Read body; one Source-to-Read transition displayed the document. The cause and ordinary foreground reproduction remain unconfirmed ([#29](https://github.com/magicsih/leaflit/issues/29)). Rich-text Write, printing, PDF export, syntax highlighting and automatic updates remain deferred. Full-body formula copying can produce duplicated or fragmented text ([#26](https://github.com/magicsih/leaflit/issues/26)); ordinary Source dark appearance remains unverified ([#27](https://github.com/magicsih/leaflit/issues/27)). Spoken VoiceOver, earlier macOS, actual Finder drops and a network-isolated run also remain unverified.

Matched 100KiB runs measured total process footprint medians of 130.6 MiB in Read and 145.0 MiB in Source after Read. These are scenario measurements, not isolated editor cost; the original 60 MiB target is not met. See the [Source verification and measurement protocol](https://github.com/magicsih/leaflit/blob/f7f6cd9c74e3d601b6a7beca60a65adc3d698851/docs/qa/source-editing-0.3.0.md) and [preceding performance work](https://github.com/magicsih/leaflit/blob/f7f6cd9c74e3d601b6a7beca60a65adc3d698851/docs/qa/product-followups-0.2.1.md).
