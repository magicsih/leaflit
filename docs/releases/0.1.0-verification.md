## Verification

| Check | Observed result |
| --- | --- |
| Independent source review | Passed on the fixed candidate, including the release packaging changes |
| Independent complete checks | Web 4, standalone core 6, packaging 7 and Xcode 19 passed; npm production audit reported 0 vulnerabilities |
| Normal Release build | Passed on the same candidate; the executable before Developer ID signing matched the original UI-reviewed binary |
| Packaging regression | A temporary app with the bundled shell launcher survived ad-hoc signing, ZIP transfer, extraction and strict signature verification |
| Extracted signed app | Strict signature, notarization ticket and Gatekeeper passed; app launched |
| Signed document reading | Mermaid labels, inline math and display math were visible in the actual app |
| Signed launcher and navigation | Bundled launcher opened a space-containing file path; relative navigation and Back passed |
| External web link | A user click opened `github.com/magicsih/leaflit` in the default Chrome browser |
| Public-download app | Unauthenticated ZIP matched the verified artifact; extracted app passed signature, ticket and Gatekeeper checks, then launched and rendered the document |
| Cask syntax and style | `ruby -c` and `brew style` passed |
| Online cask audit | Failed one policy check: `v0.1.0 is a GitHub pre-release.` Full audit is not passed |
| Actual Homebrew install | `brew install --cask magicsih/tap/leaflit` installed the app and launcher successfully |
| Installed identity and security | Installed executable hash matched; strict signature, ticket and Gatekeeper passed; quarantine remained present |
| Installed command | `/opt/homebrew/bin/leaflit` resolved to `/Applications/Leaflit.app/Contents/Resources/leaflit` and opened the document in the installed app |
| Source immutability | `Fixtures/Release Preview.md` SHA-256 was unchanged after signed, public-download and Homebrew-installed reading |

The core tests are included in Xcode's count and are not additional unique tests. Independent verification logs and machine-readable signing, download and installation records are ignored build output under `build/`. The three historical UI rounds were retained because product behavior did not change during distribution preparation. The signing fix moved the shell launcher to Resources as required by Apple's code-signing layout; no product code changed.

Before installation, no existing app at `/Applications/Leaflit.app` or `leaflit` command was present. The verified installation remains available. Test app processes were closed. Finder defaults and security protections were not changed.
